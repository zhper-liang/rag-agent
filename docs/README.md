# 文档索引

本目录的文档分三类，各管一件事：**现在是什么样**、**做过什么**、**还要做什么**。

| 目录 | 内容 | 状态 |
|------|------|------|
| [架构与关键信息/](#架构与关键信息) | 现行架构、接口、模块设计、运维手册、关键结论 | 维护中，改代码就要同步 |
| [已完成的计划/](#已完成的计划) | 历史计划、调优记录与评测数字 | 只读，不再维护 |
| [计划/](#计划) | 尚未完成的事项、已知限制、下一步 | 随进展更新 |

改动任何一篇都要遵守 `CLAUDE.md` 里的约定：参数只写进 `config.yaml`，文档只说明含义和配置键；跨模块契约改一侧就要同步另一侧。
