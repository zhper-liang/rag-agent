## 3. 先做难点，同时先发第一批接口

**第一批（开工当天交付，三条线在等）：**

1. `llm/structured.py` 的 `structured_call`（大模型生成 §6.2）。返回 None 的问题已经记在 §14：先按 D-005 的推荐方案实现（None 当失败，切备用），实现后发「交付」。
2. `prompt/env.py`：Jinja 环境（autoescape 关、`StrictUndefined` 开）、`escape_tags`、`attr`、`RESERVED`（Prompt 组装 §5）。做完把 `tests/test_fixtures.py` 里从文档解析 RESERVED 的部分改成导入代码里的 RESERVED。那个文件是共享文件，要先取 `fixtures` 锁，并在提交里写明。
3. `graph/deps.py`：节点怎么拿到 cfg、客户端、信号量、写流函数，按 D-003 的推荐方案定下来，发给 L2。

**难点：**

4. **流式生成的重试与切换（大模型生成 §6.1、§7）**。规则：
   - 只在首个可见 token 之前重试
   - 首字超时直接切备用
   - 4xx 直接切备用
   - 开始输出后出错不重试，标记 `interrupted`
   - `ThinkFilter` 跨 chunk 边界
   - 只有思考内容时不能误判为首字超时

   大模型生成 §12 的九条测试全部要写。注入故障用 `tests/stubs/llm_server.py` 的 `/_stub/script`。
5. **后处理的引用解析（后处理 §3~§8）**。规则：
   - 代码块屏蔽，未闭合的块屏蔽到结尾
   - 识别补充说明标题
   - `句子。[1]` 和 `句子[1]。` 都要能分句
   - 支持度校验，超时则全部保持 `unverified`
   - 位置按 UTF-16 计算（有 emoji 时要对）

   后处理 §12 的七条测试全部要写。正文永远不改，只追加 `final` 事件。
6. **Prompt 组装**（Prompt 组装 §3~§11）：§14 的六类测试全部要写（快照、注入、代码不被破坏、图片占位符、历史裁剪、StrictUndefined）。
7. **图组装 `build_graph`**（总揽 §4.2）。边的规则：
   - 所有回答路径都汇到 `postprocess`，`clarify` 也经过它
   - grade 是 `rerank` 之后的条件边
   - `rewrite` 有新查询回 `retrieve`，没有就去 `fallback`
   - 用 SQLite checkpointer 按 `session_id` 保存

   L2 的节点没交付时用占位节点，把边和路由测到；L2 交付后换成真实节点。
8. **API**（大模型生成 §8）：`progress` / `meta` / `token` / `final` / `error` 五种事件；客户端断开时取消图的执行；原文下载只接受过了正则的 `doc_id`，通过登记表查出路径，不接受客户端传路径（后处理 §7）。
